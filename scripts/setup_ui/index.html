    需要在 GitHub 上处理什么？
    1. 进入自己的 GitHub 仓库，打开 Actions。如果 GitHub 提示工作流未启用，请按页面提示启用。
    2. 仓库需允许注册自托管 runner。工作流回存和选题确认还需要能够推送至 main。组织策略或分支规则拦截时，请按仓库的权限要求处理。
    3. 回到本页选择「重新检查」。定时任务执行时，请保持这台 Mac 开机、联网并运行执行器。

    打开当前仓库的 Actions ↗

    04 Obsidian 阅读库 可选 等待检查

    用单独的 Vault 阅读同步到本机的研究资料。你可以随时设置。

    阅读库路径
    下载 Obsidian ↗

    首次在 Vault 管理器中选择「打开文件夹作为仓库」，然后选中上方的阅读库路径。

    分库、GitHub 更新和多设备阅读
    • 分开使用。 把阅读副本单独打开成一个 Vault，个人笔记继续放在自己的 Vault 中。打开现有文件夹
    • 从 GitHub 更新。 研究和写作回存后会自动刷新阅读副本。其他更新可用本页「从 GitHub 更新资料」拉取。遇到本地改动时，先另行保存笔记，再重试。
    • 在其他设备阅读。 已开通 Obsidian Sync 时，在这台 Mac 的阅读库中登录 Obsidian，在「核心插件」启用 Sync，再到「设置 → Sync」创建并连接远程 Vault。在手机或其他电脑上用「设置 Obsidian Sync」连接同一个远程 Vault。GitHub 更新集中在这台 Mac。设置 Obsidian Sync
    每轮研究会保存什么
