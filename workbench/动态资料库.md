## 阅读边界

- 仅筛选 Agent Memory 正式目录、相应类型与正式记录标记，排除 test、配置和准入回执。
- 标题列使用文件 Frontmatter 的中文标题；现有文件名和证据链不变。
- 日期来自文件名中的研究轮次，而非文件下载时间、修改时间或原文发表时间。
- 表格只展示公式列。选题授权、人工编辑和核验以各自正式流程为准。
- Bases 负责浏览，不重新执行准入散列核验；需要追溯时打开原文中的准入记录。
- 在 GitHub 或未启用 Bases 时，使用[普通 Markdown 索引](资料索引.md)；该索引标明整理日期，不自动声称实时。
