# 逐篇研究总结

Research Agent 逐篇读取 [collection](../collection/README.md) 中已固定的完整原文，生成详细的中文技术解读，经独立模型审阅通过后保存到这里。

按研究方向和采集批次组织，当前默认方向为 [Agent Memory](agent_memory/README.md)。每篇总结说明问题、方法步骤、实验或工程结果、适用条件和局限；正文连续可读，原文与本地归档链接集中在篇末。

本阶段只执行 Research，不自动运行 Insight 或 Writing。命令、预算和补跑方法见 [Research 说明](../workflows/research.md)。
