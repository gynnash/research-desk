# MIRIX-2.0: Multi-Agent Memory System

作者报告，在使用 gpt-4.1-mini 抽取和回答的对话记忆评测中，加入超图索引与语义 AutoDream 后，LoCoMo 准确率从平面记忆的 85.7% 升至 91.4%，LongMemEval-S 从 58.8% 升至 72.6%。关键设计是将记录与索引分离：语义整合只调整实体索引，不改写已存证据；程序记忆分支则会修改技能。

## 保留记录，整合索引

作者让六类代理分别管理记忆，仅对情景和语义记录建立超图。记录先提交到向量数据库，图写入失败不会回滚记录。多元事实框架将参与者、角色和日期、价格等属性绑定，并引用来源记录；无明确日期的情景事件用不可变记录标识区分，避免仅因措辞相似而合并。

情景和语义记忆的正常检索先选择图锚点，再取得事实及来源记录；图读取报错才回退到直接证据检索，其他记忆类型有各自的检索路径。单值查询的基础记录与引用记录预算分别为 6 和 4，计数查询为 8 和 12。语义 AutoDream 在写入路径之外合并重复实体的引用并重连边，不改写证据记录，也不合并事件事实节点。

## 对话召回的组合收益

作者报告，平面记忆、加入超图、再加入 AutoDream 的 LoCoMo 准确率依次为 85.7%、88.4%、91.4%；LongMemEval-S 对应为 58.8%、70.0%、72.6%。抽取和回答使用 gpt-4.1-mini，两项基准由 gpt-4o-mini 三次投票评分。消融支持逐步加入组件的收益，但未单独隔离多元框架、来源引用或回答验证的贡献。

## 程序记忆修改可执行技能

作者让 AutoDream 从任务会话提炼经验与错误，再由管理代理创建、修改或删除技能，并核对引用文本。以 GPT-6 Luna 为执行模型、训练后冻结记忆，在 134 个留出 ALFWorld 任务上，三次运行的平均成功率为 76.4%，无记忆为 69.4%，AWM 为 73.6%。这评估的是整条技能提炼流程，其检索独立于语义超图。

作者报告，关闭 AutoDream 的图配置在五项计时基准上均比 HyperMem 回答更快；但三项文档任务的摄取耗时是平面记忆的 3.8—4.0 倍，回答也比平面配置更慢。因此，图索引并非天然节省成本，而是为组织证据增加预处理与查询处理。
