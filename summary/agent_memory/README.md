# Agent Memory 逐篇解读

这里保存独立审阅通过的论文、博客详细总结，路径为 `<批次 ID>/<资料 ID>.md`。

论文重点解释作者要解决的问题、方法机制、记忆的生命周期、实验设置与比较结果；博客重点解释设计思路、工作流程和工程取舍。原文没有的数值或实验不会补造，作者结论与我们的推断会自然区分。

每篇文章末尾可回到对应的[采集原文](../../collection/agent_memory/README.md)。阅读范围限于实际取得的完整抽取正文，不等于实验复现。
