# 记忆筛选与记忆组织：Agent究竟该留下什么？

以《Beyond Marginal Influence》摘要中的任务时记忆子集选择为切入点，与《Memory Blocks》历史笔记记录的记忆块组织概念并置；明确两者不是直接效果对照，且历史材料须重新核实。

当前材料同时包含记忆选择研究摘要和记忆块历史笔记，可作为提出评测问题的线索；不代表领域热度或方案优劣。
