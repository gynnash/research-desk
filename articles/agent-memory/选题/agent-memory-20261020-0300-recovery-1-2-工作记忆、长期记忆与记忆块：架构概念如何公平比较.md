# 工作记忆、长期记忆与记忆块：架构概念如何公平比较

对照 《Co2In》 摘要描述的双层记忆与巩固流程、《Memory Blocks》 历史笔记记录的记忆块组织概念；明确二者任务背景不同，提出统一评测方案，而非比较性能高低。

这批资料包含一个增量学习架构摘要和一份工程博客历史笔记，可用于提出跨架构比较所需的共同指标；并不表示这些方案近期普及或效果已验证。

## 适合谁读

设计长期记忆架构、知识更新流程或记忆评测的产品与研究团队

## 准备回答的问题

- 不同架构如何定义记忆边界、更新及持久化？
- 统一任务中应如何同时衡量回答表现、记忆占用与更新可靠性？

## 写作前还需要补齐什么

- 获取并核对 《Co2In》 全文及评测细节。
- 重新审阅 《Memory Blocks》 所依据的博客原文；现有历史笔记不足以核验其当前实现或效果。
