# 容量有限时，智能体应如何挑选和更新记忆？

从《Edit-Your-Interest》的视频特征多样性更新和《Memory Blocks》历史笔记中的容量约束记忆块提出跨领域研究问题，明确区分设计线索与已验证的智能体记忆效果。

当前资料同时涉及有界缓存更新和有容量约束的记忆组织，可用于界定后续实验问题；材料没有证据表明这已成为行业趋势。

## 适合谁读

研究智能体记忆写入、长期信息维护与可靠性评测的读者

## 准备回答的问题

- 对话记忆中的多样性应如何定义，是否能代表信息价值？
- 容量约束与冗余控制会不会删除低频但重要的信息？
- 如何评估记忆更新对长期正确性的影响？

## 写作前还需要补齐什么

- 《Edit-Your-Interest》不研究通用智能体记忆，不能直接迁移其更新策略。
- 《Memory Blocks》是未经本次独立复核的历史笔记，需核验原文。
- 缺少统一任务下关于容量、保留、遗忘与答案正确性的对照实验。
