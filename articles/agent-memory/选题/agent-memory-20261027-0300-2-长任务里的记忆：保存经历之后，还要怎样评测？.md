# 长任务里的记忆：保存经历之后，还要怎样评测？

结合《AgentOdyssey》摘要关于长时程持续学习评测的描述与《MemGPT》历史笔记中的分层记忆线索，提出区分保留、检索和使用的验证问题；不据此推断架构有效。

这批资料分别涉及长时程评测摘要和历史架构记录，足以形成待验证问题，但没有证明某类机制的效果。

## 适合谁读

设计Agent长期交互任务、记忆评测或可靠性测试的研究者与产品团队

## 准备回答的问题

- 如何分别测量经历保留、检索正确性和实际使用？
- 长任务失误是否由记忆因素造成，还是探索、规划或接口因素所致？

## 写作前还需要补齐什么

- 需核验《MemGPT》原文及其适用范围。
- 需取得《AgentOdyssey》全文和具体评测细节。
- 缺少控制其他能力因素的统一对照实验。
