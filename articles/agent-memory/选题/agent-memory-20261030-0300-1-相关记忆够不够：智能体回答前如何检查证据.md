# 相关记忆够不够：智能体回答前如何检查证据

以《From Relevant Memories to Sufficient Evidence》摘要中的查询特定证据集思路为切入点，与《Memory Blocks》历史笔记所述记忆块组织视角作有限对照；明确区分作者报告、历史记录和待验证问题，不作优劣排名。

本批材料同时包含针对查询构建证据集的论文摘要和记忆组织的历史笔记，适合提出证据充分性这一具体问题；不据此宣称该方向近期升温。

## 适合谁读

设计长期记忆检索、问答或评测系统的AI工程师与研究者

## 准备回答的问题

- 怎样定义一个查询所需的充分证据？
- 如何区分“检索相关”与“足以支持答案”？
- 如何评测证据覆盖、来源追溯和跨记录整合？

## 写作前还需要补齐什么

- 《From Relevant Memories to Sufficient Evidence》全文、评测协议、基线配置及统计不确定性。
- 《Memory Blocks》对应原文与实现细节的本轮核验。
- 在相同模型、记忆库和题目上的直接对照结果。
