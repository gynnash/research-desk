## 写作定位

核心问题：资料已经留在系统里，为什么当前任务仍可能用不上？

读者收获：能够追问“资料在哪里、这次选了什么、答案依据是什么、结论怎样修订”，并区分架构描述、特定实验和待验证建议。

文章以 [研究报告](../reports/2026-10-18-agent-memory-memgpt-memory-blocks.md)为底稿。MemGPT 与 Memory Blocks 是两个相关案例；本文不做行业全景或产品排名。

## 开篇：从一个虚构场景进入

设想一位研究者已收藏资料，下次写文章却没有找到关键出处。明确标为说明性场景，不包装成用户案例、产品故障或已完成实验。

引出问题：从“存着”到“本次答题用对”，中间还有哪些步骤？暂不把原因归结为模型能力。
