## 研究概述

仅依据论文摘要，概述 Edit-Your-Interest 在视频编辑中使用有界特征记忆与相似性检索传播的设计；材料涉及记忆缓存、检索和更新，但不直接研究通用智能体记忆。

## 主张与证据

- **原文事实**：摘要称，时空特征记忆库（SFM）在固定内存预算下缓存前序帧的空间注意力特征。（[A5](https://arxiv.org/abs/2510.13084v2)）
- **作者声称（未独立核验）**：作者称，SFM维护代表性候选池，以减少对完整序列进行时空建模的计算开销。（[A6](https://arxiv.org/abs/2510.13084v2)）
- **原文事实**：摘要称，特征最相似传播（FMP）依据相似度检索相关缓存令牌，并将其传播至当前帧；SFM更新算法则依据特征多样性维护记忆的代表性和非冗余性。（[A7、A9](https://arxiv.org/abs/2510.13084v2)）
- **作者声称（未独立核验）**：作者称，SFM与FMP的设计改善了时间一致性并减少模糊和马赛克状伪影；摘要还称实验中该方法在效率和视觉保真度方面优于当时的先进方法。（[A8、A12](https://arxiv.org/abs/2510.13084v2)）
