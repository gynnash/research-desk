## 模拟闭环覆盖

- 官方 HTML 分节、附录及参考文献保留；PDF 同页多章节、跨页连续文本和页码引用。
- HTML 失败后读取 PDF，两者失败后明确摘要降级；错误身份/版本直接拒绝；扫描件不冒充全文。
- 输入预算包含章节标题与定位标记；长文标记 `excerpt`，逐节说明未提供字符。
- Research 与独立审阅收到相同正文和章节范围；Insight v3 复取同版本、同媒介并验证散列及请求绑定。
- 摘要升级创建独立 `update`；相同全文和已研究过的相同降级摘要不重复调用；正文恢复后可以升级。
- 同轮缓存补跑不增加模拟请求；旧 Research v1 / Insight v1、v2 提示词和报告凭据保持兼容。

复现命令见[全文阅读规范](../../../../workflows/fulltext-reading.md)。测试只使用模拟客户端，不会读取用户会员凭据或进行真实推理。
