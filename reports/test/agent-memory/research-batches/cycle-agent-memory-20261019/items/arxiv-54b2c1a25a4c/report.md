## 研究概述

本概述仅依据论文摘要，介绍其对智能体记忆评测的批评、FEB-30 基准设计及摘要报告的评测结果；未核验论文全文或实验实现。

## 主张与证据

- **作者声称（未独立核验）**：作者认为，以问答准确率评估记忆会混淆记忆内容是否正确与检索、生成表现，并可能产生掩盖记忆故障的假阳性及误判正确记忆的假阴性。（[A1、A2](https://arxiv.org/abs/2610.22209v1)）
- **原文事实**：摘要称，FEB-30 包含30条事实演化轨迹，覆盖6类诊断类别和3个难度等级；其文档由已知事实轨迹生成，以获得确定性真值。（[A3](https://arxiv.org/abs/2610.22209v1)）
- **原文事实**：摘要称，每条轨迹描述事实如何随多作者文档、邮件和对话演变，并允许在每步摄入后直接检查记忆存储。（[A4](https://arxiv.org/abs/2610.22209v1)）
- **作者声称（未独立核验）**：作者报告，在一个代表性记忆系统上，内在评测与外在评测平均相差16个百分点，44%的轨迹超过其所称的有意义差异阈值。（[A5](https://arxiv.org/abs/2610.22209v1)）
- **作者声称（未独立核验）**：作者报告，该系统仅在20%的情况下正确分类记忆操作（创建、更新、强化、取代）；摘要称这一问题在外在评测中不可见，且失效模式因类别和难度而异。（[A6](https://arxiv.org/abs/2610.22209v1)）
