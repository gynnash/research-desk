## 研究概述

该摘要研究 LLM 智能体按决策选择记忆子集的方法，重点是子集能否保留完整记忆下的行为。以下仅概述所提供的论文摘要，未核验论文全文、实验或实现。

## 主张与证据

- **作者声称（未独立核验）**：作者指出，按相关性或单条记录影响力排序，可能无法找到冗余证据或必须联合使用的证据所构成的充分子集。（[A1、A2](https://arxiv.org/abs/2610.23266v1)）
- **原文事实**：摘要称，JointCoreBench 包含九类交互、六个工作流领域、自然语言决策及精确充分集 oracle；JointCore 是按相关性成本排序、先测试记录块再测试单条记录的删除基线。（[A4](https://arxiv.org/abs/2610.23266v1)）
- **作者声称（未独立核验）**：在摘要所述的 6,912 个精确条件上，JointCore 达到 100.0% 的最低成本充分集恢复率，子集评估次数从 30.00 降至 11.13，并报告 87.8% 的活动记忆节省。（[A5](https://arxiv.org/abs/2610.23266v1)）
- **作者声称（未独立核验）**：在四类 12B–70B 模型、每个模型 432 项任务的测试中，摘要报告 JointCore 的平均模型查询数为 10.28，低于单例删除基线的 16.00；最低成本恢复率分别为 50.6% 和 43.1%。（[A6](https://arxiv.org/abs/2610.23266v1)）
- **作者声称（未独立核验）**：作者称，基线在确定性主接口下保留完整记忆行为；其他接口测试显示行为依赖接口，并明确表示该研究尚未证明记忆压缩已可用于部署。（[A7、A8、A9](https://arxiv.org/abs/2610.23266v1)）
