# MOSAIC: An Omni-Modal Benchmark for Long-Term Memory and Cross-Modal Reasoning in Conversational Agents

> TEST：运行中间产物，未正式入库。

长期多模态助手答错问题，可能是写入时丢失细节、检索漏掉证据、打包时删掉媒体，也可能是证据齐全仍读错；单一端到端分数无法区分这些原因。作者提出 MOSAIC，以923道问题组织跨11至24次会话的文本、图像、视频和音频历史，并固定阅读器、提示、预算与裁判，逐阶段替换证据表示和交付条件。最值得关注的是：通用描述与转写比原生证据低9.3分，生产打包另损失3.8分，而金标准符号事实下仍有15.4分残余误差；空间关系的损失证据最清楚，完整证据链交付与可靠拒答则仍是系统短板。

## 多模态记忆必须保留决定实体选择的细节

作者提出的 MOSAIC 首先是一套诊断基准，而非新的记忆存储算法。它针对的困难是：用户在不同月份提供的媒体，可能分别承担实体定位、候选筛选和最终取值，找回一张相关图片并不等于找回整条推理链。作者指出，既有基准或缺少音视频，或主要测试图文共指与证据查找，难以同时检验跨会话、跨模态串联及其失败位置。因此，MOSAIC 不满足于给对话附上媒体，而是在生成之前指定必须由原生载体承载的判别信号，包括背景细节、空间位置、动作顺序与次数，以及中性措辞下的高兴或不高兴语调。

作者把每道可回答题组织为一至三个必要事实，分别承担 Narrower、Selector 和 Answer：先缩小候选集，再确定实体，最后取得答案。相邻事实必须通过具体实体连接，删除任一必要事实后应无法回答；音视频判别还必须面对至少两个同类候选，避免媒体只是装饰。例如，一条示例链先读取棋盘照片背景招牌上的城镇名，再用当地工坊视频中“先挖空、后镶嵌”的动作顺序锁定雕刻师，最后依据语音中对两种包装方式的不同情绪选择答案。最终答案虽可写成短字符串，其正确归属却依赖前面各跳，不能仅凭找到答案值就视为完成记忆推理。

作者报告，数据构造从人物设定出发，先设计问题与答案，再生成证据链；程序检查和逐事实删除测试进入最多三轮修复，随后把事实分散到时间排序的证据会话与填充会话，并用泄漏约束限制提前暴露答案。媒体合成、自动过滤和人工救回44道探针误拒题后，最终得到923题，其中784题可回答、139题用于拒答。数据覆盖70个人物设定，每题历史含11至24次会话；可回答题中85.2%需要至少两个事实，75.0%需要至少两种模态。它并非模态均衡集合：99.5%的可回答题需要图像，音频和视频分别涉及54.1%与23.5%，因此分挑战分析比总体均值更重要。

## 将写入、检索、交付和阅读分别替换

作者将流水线明确为四步：写入器把历史变成记忆，检索器按问题取出单元，打包器在预算内序列化候选，阅读器依据实际交付内容作答。这里最关键的区分是“检索命中”与“进入服务商实际请求”并不相同。表示路径也有三种：Caption-Text 用视觉描述和 ASR 转成文本后建索引；Omni-Text 用全模态模型生成保留韵律的描述，但仍进行文本检索；Native-MM 则用多模态嵌入索引原始媒体，并让全模态模型读取。A-MEM 与 MemoryOS 在本评测中只接受文本派生记忆，因此比较它们时不能假定其原生媒体能力已被测试。

具体诊断在同一批784道可回答题上固定 Gemini 3.5 阅读器、提示、打包器和 Qwen3.7-Plus 裁判，再替换金标准符号事实、原生媒体、通用文本、查询无关的结构化文本，以及检索后全部交付或按生产预算交付的上下文。检索条件重放冻结的前50项排序，生产预算只交付前20个单元，每种模态最多三个媒体且总媒体不超过100 MB。评价不是准确率：主指标是含部分分的0至1语义裁判均分；另统计必要事实召回和完整链召回，并分别在排序结果与实际请求上计算。配对差异按题目重采样给出95%区间，使阶段变化不被换阅读器等因素掩盖。

## 最大残余误差不在检索，文本化损失也因模态而异

作者报告，金标准符号事实得分为0.846，说明即使必要事实齐全，仍有15.4分阅读、输出格式与裁判误差。换成金标准原生媒体后为0.783，换成通用描述与 ASR 后为0.690；查询无关的结构化写入器仅恢复至0.704，恢复量1.4分的95%区间为−0.9至3.7，不能据此宣称普遍有效。原生证据经检索但全部交付时降至0.708，生产打包再降至0.670；完整链交付比例同时从0.675降到0.491。这些结果支持在该固定配置下区分表示、检索和打包损失，但作者强调，符号事实残余并不等于纯粹的推理错误，也不是所有系统共有的因果瓶颈。

作者用题内载体替换进一步定位损失：保持问题、证据次序及其他跳不变，只改变一个必要媒体。空间配置题中，原图比仅 OCR 文本高32.0分；显式空间描述又比只列对象高15.4分，95%区间为9.5至21.5，但仍未补齐与原图的差距。这说明关系而非对象名称本身承载了事实。视频需要区分另一种问题：涉及视频的题从符号事实0.900降至原生证据0.729，显示该阅读器存在明显感知负担；然而有序稀疏帧并未显著胜过乱序帧，事件与计数文本也未显著胜过稀疏帧。后者不是时间信息可以无损压缩的证明，因为各视频挑战只有56至64道独立题目。

音频结果需要把“使用语调选择器”与“从声音恢复语调”分开。作者报告，在金标准交付下，原始音频相对 ASR 只高0.8分，加入金标准情绪标签只高1.5分，两者区间均包含零；但在399道独立韵律题上，把正确标签翻转为相反情绪，会使配对得分下降4.6分，95%区间为1.7至7.7。因此，标注的情绪选择器确实影响答案，却不能证明阅读器能可靠感知原始声音。作者还检查到转写载体中的感叹词、停顿等词汇线索，以及其他金标准跳已暴露答案值的情况。将这些近零差异解释成“韵律不重要”或“ASR 已完整保留情绪”，都超出了实验支持范围。

## 完整链进入请求，比索引是否原生更能解释部分胜负

作者报告，在固定阅读器的轨道中，A-MEM 的 Caption-Text 得分0.684，比同表示的平坦 RAG 高16.2分，也高于原生多模态平坦 RAG 的0.641；对应完整链交付比例分别为0.787、0.698和0.466。这里的原生表示优势会被媒体预算抵消：生产上限条件下，共9,338个已检索媒体未进入请求，记录原因全部是每模态媒体数量上限。另一项预算实验保持必要事实 Recall@50 为0.871不变，将前项数量降至五项并同时限制每模态一个媒体，得分下降17.7分，完整链交付降至0.184。作者特别说明，这个下降是数量预算与媒体上限的联合效果，不能单独归因于媒体上限。

端到端轨道允许各系统使用自己的控制器与阅读器，因而回答的是整体能力而非单模块优劣。作者报告，MiMo-V2.5 原生 ReAct 的可回答题得分最高，为0.732，但正确拒答率只有0.410；MemoryOS 两种文本配置正确拒答超过0.88，却在可回答题上低于0.26，误拒率超过0.61。拒答能力必须同时看该拒绝与不该拒绝的情况。失败案例也说明“找到新值”不足以处理更新：模型把墙面变化只答成“鼠尾草绿”，漏掉旧颜色至新颜色的对照，仅获0.5分。作者据此将后续目标归结为保留模态特有信号、交付完整链并忠实读取，而不是只提高一个混合端到端分数。

## 适用条件与仍需验证的问题

已阅读抽取全文，未独立复现实验。阅读范围包含所提供的正文、参考文献及可用附录文本，但文本抽取不能核实图像内容、版式及数学渲染，也可能遗漏图表或附录中的非文本信息；例如关键提示附录在输入中仅有介绍，不能视为已核查完整提示配置。全部阶段结果来自作者的一次规范配对运行，主要归因依赖固定阅读器与裁判；金标准和检索上下文仍在干扰项与组成上不同，因此阶段差值是匹配协议下的关联，不是完全隔离的因果效应。第二阅读器只在120题试点复核部分阶梯，其不限量交付条件因大量超时不能用于阶段归因。

人物设定、证据会话和媒体由合成流程产生，填充文本另取自公开会话池，尚未验证自然积累的私人多模态历史。模态覆盖明显偏向图像，视频挑战样本量不足以排除较小时间效应；音频文本化载体存在副语言词汇线索，金标准其他跳也可能暴露答案。人工分层估计的答案正确率约97.8%、证据充分率约96.6%，仍含生成媒体歧义；救回题采用三人一致判无效才排除的规则，并非三人一致认可。探针通过题与人工救回题的原生证据得分差异也提示选择偏差，绝对原生得分可能偏乐观。多重探索性比较的区间未作统一校正。

拒答控制主要由信息抽取型模板删除证据构造，虽然历史长度匹配，问题文本仍可部分预测拒答身份，因此不能将结果推广为不依赖题型线索的校准能力。测试系统不得接收必要事实标记、答案会话或题型等金标准构造元数据。A-MEM、MemoryOS 未接入原生媒体索引，端到端比较同时改变表示、检索底座、控制器和阅读器，不能解释为架构的普遍排名；真实部署中的用户同意、保留期限与隐私控制也不在该基准验证范围内。
