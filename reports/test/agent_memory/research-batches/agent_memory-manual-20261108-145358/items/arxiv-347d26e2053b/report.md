# MemComposer: Learning to Assemble Memories for LLM Agents via Reinforcement Learning

> TEST：运行中间产物，未正式入库。

MemComposer 针对智能体记忆中的具体困难：语义相似的历史轨迹未必能指导当前行动，固定检索数量与排序也可能降低成功率。作者在相似度检索之后加入可训练的组装器，联合读取请求与候选摘要，决定选哪些、选多少及如何排列，再把完整轨迹交给冻结执行器。训练采用 ExPO，以多次完整交互的成功率比较组装方案，而非预测单条记忆的相关性。在三个客服领域、两个执行器上，作者报告平均成功率与四次全部成功的比例均领先，执行器接收的记忆 token 分别减少16.9%和4.9%；固定集合的重排实验进一步显示，顺序本身具有可测的影响。

## 记忆价值取决于整组经验如何指导执行

作者提出，智能体需要的不是单纯“与请求相似”的文本，而是能改变后续行动的经验。前期观察显示，增加记忆数量并不稳定提高成绩，不同领域偏好的数量不同；即使记忆集合不变，换一个排列也会改变具体任务的结果。MemComposer 因而将决策对象从单条记忆的分数改为整个有序子集：给定请求与候选池，同时决定成员、数量和顺序，允许一个也不选。作者将这一点与逐条估计效用的 MemRL、Memento 区分开来。相对于文中讨论的 RAG 场景，这些候选的主要价值不是提供答案事实，而是引导执行器完成多步工具操作、遵守政策并避免旧错误。

记忆首先离线写入，而不是在测试交互中持续增长。作者让冻结执行器对每个训练任务独立运行8次，再由同一模型结合结果、评测反馈和参考解进行事后复盘。失败轨迹标出最早的错误行动及替代做法；成功轨迹也接受过程审计，有严重过程错误的被标为 fake pass，但不改动环境原本给出的成功奖励。确定性检查核对引用轮次、结果一致性和格式，不通过就连同轨迹删除。最后每个训练任务最多保留两条，尽量兼有成功与失败。因此库存并非成功示范集，而是包含行动、历史结果及纠错解释的程序性经验库；测试任务不参与建库。

取出记忆时，作者只用用户开场请求建立索引，以 Qwen3-Embedding-8B 的余弦相似度取得前10条。每条记忆有两种表示：完整轨迹加复盘平均约2.3K—3.0K token；供组装器读取的摘要平均约1.0K—1.4K token，含开场请求、结果标签、关键行动概述及复盘。组装器联合读取请求和十份摘要，输出简短理由与候选编号的有序列表；选中后才把对应完整版本按该顺序插入执行器系统提示。测试时每个任务只选择一次，并在四次试验中复用。训练期间执行器、检索器与库存都固定，改变的是上下文组装策略，而非记忆内容或执行器参数。

## ExPO 用完整交互的结果学习组装策略

作者提出的 Experience Policy Optimization（ExPO）沿用 GRPO 的组内比较框架，但奖励来自执行器完成任务后的结果。每个输入采样8个组装序列，每个有效序列固定记忆和顺序，以不同基准种子完成8次交互，取二元成功结果的平均值，再扣除数量与格式惩罚。相同序列可共享试验，基础设施错误会触发重采样。数量惩罚按条数而非 token 计算：零售、航空每条扣0.01；电信前7条免费，超出后每条扣0.02。最大数量惩罚低于一次成功带来的1/8奖励增量，因此格式条件相同时，它只偏好同等任务成绩下更小的选择，不会压过成功率差异。

训练会丢弃任务成功率完全相同的采样组，避免仅靠“更短”或“格式更好”产生学习信号。保留组内的优势是最终奖励减组均值，不除以标准差，以免放大接近结果中的噪声；随后用 token 级裁剪策略目标更新组装器，不使用参考策略 KL 惩罚。作者以 LoRA 训练30次策略更新。为扩大输入变化，每个训练任务生成四种客户开场，多数设置还把前20个候选分成两个十条窗口；检索排除同任务记忆，测试则固定单个开场与前10条。代价主要在完整交互：采样与环境模拟占每步墙钟时间的69%—91%，其开销明显不同于只对候选计算相关性分数。

## 成绩提升需要结合比较条件与顺序对照理解

作者在 τ²-bench 的零售、航空、电信领域评测，测试任务分别为40、20、40个，统一由 GLM-4.7 模拟用户。每个任务运行四次：pass1 是平均成功率，pass4 是四次全部成功的任务比例，不是“至少一次成功”；跨领域成绩取等权平均。同一执行器下，各选择方法共享冻结模型、库存与前10个候选。基线包括无记忆、相似度或轨迹长度启发式、未训练选择器、预训练重排器，以及 MemRL、Memento。启发式在测试集上从指定预算中挑最好配置；MemRL 关闭写回，仅比较价值感知检索，Memento 则适配为离线训练的案例评分器。这里比较的是固定候选池内的组装，而不是完整在线记忆系统。

作者报告，Qwen3-4B-Instruct 下平均 pass1、pass4 为50.8和32.5，较各指标最强基线高5.9和5.0个百分点；Ministral-3-8B-Instruct 下为63.5和40.0，pass1 高4.6点。但 Ministral 电信任务上，MemRL 的76.2/55.0仍高于其75.6/52.5。相对各执行器最强基线，记忆 token 少16.9%和4.9%：该指标使用执行器自身 tokenizer，包含172 token 固定头，无记忆计零，跨领域按测试试验数加权，与成绩的领域等权口径不同，也不代表端到端成本同比降低。额外的 ALFWorld 实验在133个未见测试游戏上达到82.0%，高于 Memento 的79.7%，但双物体拾取类型仍无方法超过30%。

行为分析中，零售任务的平均选择数从2.52增至3.73，所选记忆平均相似度名次从3.21移至4.35，成功经验占比从45.5%降至35.6%。省 token 因而不等于比未训练选择器选得少。失败换货记忆使一个任务从0/4提升至4/4，但历史失败在价格沟通，当前测试不检查价格陈述，且训练、测试涉及同一客户和订单，可直接复用换货操作。该案例支持失败轨迹含有局部可用行动，并不证明历史错误已被纠正。另一个更直接的对照固定已选集合，在 Ministral 全部测试任务上改用四种相似度或长度排序；学习顺序领先3.8—8.5个 pass1 百分点，隔离了顺序效应，但未证明排序最优。

## 迁移结果支持可复用的组装能力

作者不经重训地更换领域、执行器或库存。零售训练的 Qwen 组装器迁移到航空后，pass1 为53.8，与领域内训练的52.5接近；迁移到电信则以1.2点 pass1 换取2.5点 pass4。换成 Ministral 执行器及其库存后，迁移组装器在零售达到70.6/50.0，针对 Ministral 训练的是75.0/47.5，体现平均成功率与稳定性的取舍。另一组实验固定 Qwen 执行器，在零售、航空更换更强模型生成的库存：组装器在10个领域—库存组合中的9个不低于相似度 top-5，并在每个未见库存上提高两领域平均 pass4，平均增益9.1点。作者据此认为，更好的存储内容不会消除组装需求。

我们据此推测，这项工作的意义在于把“检索之后的上下文组装”确立为可独立训练的决策层，而不是证明相似度检索已经无用。相似度仍决定候选边界，组装器无法选到池外经验；摘要决定它能看到哪些线索，完整轨迹则决定执行器实际接收什么。整组任务奖励能够容纳经验互补和失败中的局部价值，但也把内容与顺序的信用分配混在一起。工程上，应将执行器上下文节省与组装器读取候选、生成选择及训练模拟的成本分别核算。对于长期智能体，它更像可插入固定记忆库的读取模块，而不是已经覆盖持续写入、遗忘、冲突解决与跨会话个性化的完整方案。

## 适用条件与仍需验证的问题

统计结论受每领域20—40个测试任务限制。作者采用10,000次按领域分层的任务配对 bootstrap；合并两个执行器后，pass1 相对所有基线的区间排除零，但 pass4 相对 Complexity、Memento 不排除零。分执行器看，相对最强基线的 pass1 增益区间都包含零，不能表述为各执行器上的决定性胜利；同时未做多重比较校正。测试集挑选启发式预算、固定库存下对 MemRL 和 Memento 的适配，也限定了比较对象，不代表全面击败其原始在线系统。

适用范围是完整历史轨迹加复盘组成的程序性记忆，执行器仅覆盖4B、8B模型；尚未验证事实规则型语义记忆、特定用户历史或前沿规模执行器。复盘依赖训练任务的参考解与评测反馈，确定性检查不保证解释语义正确。官方划分允许客户与订单重叠，且失败换货案例的当前任务不评估历史出错的价格沟通，因此该案例不能证明抽象技能迁移或错误纠正。顺序由整组奖励隐式学习，未与全排列最优解比较，也未全面消融选择、排序及奖励组件。记忆 token 节省不包含组装器与训练模拟成本，报告的本地 GPU-hours 也不包含全部 API 开销。
