# Memory Tax: Dissecting the Net Value of Agent Memory

> TEST：运行中间产物，未正式入库。

智能体把历史对话压缩、抽取或组织成记忆后，究竟比直接检索原始记录多创造了多少价值？本文针对这一难以分离的问题，以原始历史上的混合检索为参照，把逐题得失拆成“记忆收益”和“记忆税”，再用理想证据回放、信息保留标注及检索轮次分析，区分写入损失与访问障碍。作者在三个对话记忆基准、三种骨干及多类系统上报告：不少复杂记忆以更高成本取得更低准确率，但部分任务确实受益于抽象和重组。最值得关注的工程方向不是取消记忆，而是保留回到原始证据的路径，并让过去的检索经验参与后续记忆构建。

## 记忆的净价值必须扣除原始检索已经解决的部分

作者提出，长期记忆的共同流程是：把交互历史经写入过程转换为持久存储，收到问题后取出相关单元，再交给生成器回答。单元可以是摘要、事实、结构化记录或情景条目；直接检索原始历史则尽量不改写内容。论文的贡献不是另一种存储架构，而是用这个低加工参照分离记忆的边际价值：记忆答对、单轮 RAG 答错的题构成收益；RAG 答对、记忆答错的题构成“记忆税”。两者的差决定相对准确率的净变化。因此，这里的“税”首先是逐题正确性损失，不是 token 费用，也不是脱离参照系统的绝对属性。

作者强调，重组历史同时带来收益和风险。平面存储抽取事实或笔记，分层系统在不同生命周期或抽象层之间迁移、合并和更新内容，图系统通过关系扩展检索，训练策略则学习写入、更新和使用操作。案例分析中，短小事实能减少无关上下文，多跳连接能汇集跨会话证据，隐含偏好可变成显式条目，相对时间可锚定为日期，遗忘请求也可更新存储状态。它们改变的是未来可访问的信息形态，而不只是给回答增加上下文；但同样的抽取、合并或改写也可能删除细节、分散证据，因而不能仅凭机制的设计目的判断其净收益。

## 强基线来自保留边界的混合检索，而非裸向量搜索

作者的 RAG 按对话轮次或观察步骤切块，不跨会话边界；短轮次合并至约 1024 字符并保留末轮重叠，超过 8192 字符的长轮次再用重叠窗口拆分，各块附会话时间。查询时，BM25 与稠密检索分别取候选，去重后用 Qwen3-Reranker-0.6B 重排，再送入共享问答提示。双轮版本还让骨干判断证据是否足够，不足时提出后续查询，从剩余池检索。这意味着文中的“naive”指没有额外语义记忆构建，并非没有检索工程。作者逐项替换分块、检索器、嵌入和重排器，报告多数变体仍较强；破坏轮次边界或仅用词法匹配时下降更明显。

作者在 LongMemEval-s 的跨会话问答、PersonaMem-v2 的隐含偏好四选一，以及 MINT-Eval 的多目标干扰任务上测试三种骨干。后两者分别抽取 40 个、60 个语料，GPT-5.6 Luna 的 LongMemEval-s 另用 100 个语料子集。短答由 Qwen3.6-27B 对照参考答案判定，选择题优先精确匹配选项。为避免相同 top-k 对不同粒度单元造成偏差，作者用 Retrieval Scope 衡量检索至回答期间模型读到的单元 token 占可检索存储的比例，再调节各系统 top-k。这个控制旨在避免记忆被过窄检索限制，并不等于各系统拥有相同推理 token 预算。

在 Qwen3.6-27B 上，作者报告 LongMemEval-s 的单轮、双轮 RAG 准确率分别为 77.6%、81.4%，A-Mem 为 79.4%，OpenViking 为 58.8%；因此，系统是否“超过 RAG”会随参照轮次改变。PersonaMem-v2 上，MemOS 达到 50.2%，高于双轮 RAG 的 48.7%，但在这批 40 个语料上，前者构建消耗 44.8M token，问答消耗 1.31M；后者无需 LLM 构建，问答消耗 7.68M。这个对照同时呈现准确率收益、离线投入与在线节省，不能缩成“复杂记忆总是更差”。主结果表主要对照双轮 RAG，而逐题收益与税的拆分使用单轮 RAG，阅读时必须保持这一条件区别。

## 证据可能在写入时消失，也可能保存后仍取不出来

作者先用理想证据回放定位写入损失：分别只提供支撑答案的原始轮次，以及与之对应的记忆单元，让检索失败不再干扰比较。映射允许一个原始轮次对应多个单元，也允许因信息丢失而没有对应项；非确定映射由两个模型独立筛选，少量分歧交给人工。微观分析另从三个基准抽样 500 个原始轮次，人工比较其完整对应单元集合。标注中，MemoryOS 的信息完全保留比例为 98.4%，SimpleMem 为 65.6%，后者另有 27.6% 部分丢失。这支持写入损失确实存在，但保留率本身不能代替最终问答能力。

作者进一步报告，MAGMA、LightMem 在只给理想记忆单元时，成绩接近只给理想原始证据，却远高于正常检索成绩，说明问题不全在内容是否保存。检索回放每轮移除已返回单元，继续检索直到收齐该题全部理想证据或达到轮数上限；许多记忆系统首轮完成证据恢复的题目少于 RAG。案例归纳出三种障碍：一个轮次被拆散后，必要片段排名靠后；事实被长画像或额外说明稀释；改写使措辞乃至含义偏移，降低查询匹配。作者也比较同一证据改写前后的嵌入相似度，但仅把它作为访问障碍的指示，因为部分系统还依赖图扩展、过滤等机制。

记忆税还受消费模型和评测任务影响。作者交叉使用三种骨干构建、读取记忆，报告不少系统切换回答模型后的分数变化大于原始 RAG，显示额外脆弱性。扩展评测中，Qwen3.6-27B 的混合 RAG 在 LoCoMo 为 75.3%，在 MINT-Eval 为 28.6%；IDF 关键词检索在 LoCoMo 已有 58.8%。但这里 LoCoMo 排除了第 5 类对抗性／拒答题，MINT-Eval 使用分层子集，两者均采用本文统一裁判协议，并非直接照搬官方评测。作者据此指出部分设置较适合检索、复杂记忆的提升空间有限；这些跨基准分差不是严格可比的难度量尺，准确回忆本身也仍是有意义的需求。

## 跨任务得失指向可恢复而非不可逆的记忆

作者用 Qwen3.5-4B 扩展到经验记忆：训练或开发集积累经验，测试时冻结；RAG 取描述最相似的两条原始轨迹，其他方法提炼工作流、策略或技能。ALFWorld 上，Memp 成功率为 76.1%，高于 RAG 的 73.1%；AppWorld 上，其任务目标完成率为 14.3%，低于 RAG 的 22.6%。世界模型的 MemoBench 则要求物体经历物理变化、离开视野后，重现时保留更新状态，本文使用 25%、即 90 个样本。直接检索帧的 I3DM 得到 SSIM 0.430、1−LPIPS 0.476，MagicWorld 分别为 0.433、0.412，两指标均越高越好。不同任务和指标下的例外，不支持“低加工普遍最优”的排序。

作者提出的修补原则是让加工偏差可恢复：正常记忆检索之外，同时检索原始历史，把两路候选联合重排后回答，以补回构建时丢掉或检索时遗漏的证据。另一条反馈路径是把过去的问题及检索到的证据写回存储，使曾经需要深层检索的材料在相似需求下更容易找到。作者称两种概念验证均有效，但抽取文本没有对应结果表的可核查数值。更长期的取舍在于构建时机：提前构建必须猜测未来需求，即时构建更有针对性却增加在线延迟；作者因此建议利用兴趣、习惯和访问模式预测未来相关性。这里的研究方向不是增加存储复杂度本身，而是控制何时加工，并保留加工不足时的恢复路径。

## 适用条件与仍需验证的问题

已阅读抽取全文，未独立复现实验。阅读范围包括正文、可用附录与参考文献，但文本抽取不验证图像、版式或公式的忠实呈现；部分案例只有图题，问答与裁判提示也只保留表题，设计改进所指结果表未出现在可核查文本中，因此不能补写图中案例、完整提示或改进幅度。

结论主要适用于静态、离线、英语评测，以及文中选定的系统和配置。PersonaMem-v2、MINT-Eval 和 GPT-5.6 Luna 的 LongMemEval-s 使用子集；基线并非穷尽，进一步系统专项调参可能改变排名。Retrieval Scope 只近似控制相对访问范围，既不严格等同推理成本，也存在少量大单元系统的例外及实际配置偏差。主表对照双轮 RAG，逐题记忆税对照单轮 RAG，不能混用；扩展基准的分数还应结合题型排除、子集和统一裁判协议理解。

诊断依赖可获得的理想证据及其记忆映射：没有理想证据的题被排除，模型筛选映射的人工抽查仍有冗余或遗漏。跨骨干变化和世界模型不同系统的比较不足以单独归因于某一种记忆操作。长期在线更新、交错查询、多语言交互，以及更多模态和参数化记忆仍未充分覆盖；作者关于需求预测和检索反馈的方向性建议，不应改写成已验证的部署收益。
