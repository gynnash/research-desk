# 从 MemGPT 到 Memory Blocks：Agent Memory 的机制与工程边界

研究日期：2026-10-18（Asia/Shanghai）

研究主题：Agent Memory

状态：首轮研究草稿，AI 辅助整理，待用户复核；未复现实验。

## 研究问题与结论

研究问题：长期保存的资料，怎样成为当前任务中可核验的依据？本报告从两份材料提取机制线索，并讨论它们对 ResearchDesk 人工研究流程的启发。

本报告提出两条工作假设：

1. 将保存、找到、进入本次输入、正确使用分开检查，可能更容易定位研究材料使用失败的环节。
2. 明确内容用途和写入权限，有助于组织审阅；摘要是否可信，仍需检查出处与修订依据。

以上是本报告的综合判断，尚未通过 ResearchDesk 的对照实验验证。

## 两份材料如何互补

P 提供有限窗口下组织信息和执行检索的机制案例；B 提供状态组织与权限表达的工程视角，分别见 E1、E2。两者共同启发我们把“资料是否存在”和“当前任务能否用对”分开审阅。

本报告进一步推断：研究系统需要同时关注资料、任务所选依据和当前结论之间的关系。原始资料可完整保存，但一份过时摘要即使带有来源链接，仍可能误导后续写作。这一推断需要通过实际任务检查，不能由“有检索”或“有分块”直接推出质量保证。

## 证据限制与后续验证

- 来源集中于同一技术路线，不能据此给出方案排名或“主流方向”的判断。
- 论文与博客采用不同证据形式；博客的能力主张没有在本文配套受控对照，见 [B 原文](https://www.letta.com/blog/memory-blocks/)。
