# 三 Agent 工作流目标对齐审查

审查基线：`8bd1212`。本次只调整现有采集、历史综合与阅读导航，不启动真实研究、Writing 或公众号发布；原正式资料、人工笔记和 Obsidian 配置保留。

## 目标与当前差距

目标链路：近两个月论文/博客与社区材料 → 未选资料去重 → 可核实关注度排序 → 最多5份正文研究 → 比较与180天历史综合 → 洞察、研究方向、选题 → 人工确认 → Writing → GitHub → Obsidian。

| 环节 | 审查前实际情况 | 本次处理与剩余边界 |
| --- | --- | --- |
| 时间窗 | 初始7天，完整扫描后按游标缩小；旧pending可绕过窗口 | 新轮次固定滚动60天，以首次发表日筛；不再消费跨轮pending。旧轮次补跑继续用旧配置 |
| 候选覆盖 | arXiv仅首页20条，博客仅列表首页 | arXiv增加日期查询与20条一页的有界分页，每来源最多80条；博客归档分页仍缺失，不能承诺穷尽两个月 |

| Writing | 真实页面确认、独立审阅和三稿已接通 | 保留人工确认；不因热度或Insight通过而自动批准写作，更不自动发布 |
| 原文归档 | Git只有来源卡、短证据、分析和原文链接；全文仅在内存 | **仍未满足原文全文副本沉淀到Git。** 本次没有隐式保存整篇文章/PDF，后续需确定快照/附件存储范围与方式，避免把研究结果误称原文归档 |
| 阅读体验 | 首页与手工索引停在10/27；source卡重复整个分析 | 首页改稳定入口；一个可核验自动索引显示至10/30，新来源卡仅保留取材记录和分析链接。旧内容保留、不搬目录 |

## 热度的实际含义

采用透明的观察值：`log1p(HF推荐) + log1p(HN点数) + 0.5×log1p(HF评论) + 0.5×log1p(HN评论)`。只有实际获得的计数参与；缺失保持unknown，并注明分数只代表已观察信号的下界。

HF论文信息按arXiv基础编号核验，HN只计原文身份匹配、讨论发表在本轮窗口内的帖子。HN最多检查10个搜索命中，“未检出匹配讨论”不等于全网零关注。每轮最多240次provider lookup，HTTP有限重试和重定向另受抓取器限制；这不消耗模型请求预算。论文已在首次发表60天范围内，其HF计数仍为观测时累计值，不伪造“两个月新增点赞”。

不同社区规模和推荐机制不同，简单评分带有平台偏差；热度也不代表技术结论正确。当前应称“已发现候选中的社区关注度优先”，不能声称“全网最火”。API失败/计数缺失会记录partial/unknown，信号不足则少选或不选，不退回最新排序冒充热门。

依据：[HF paper_info](https://huggingface.co/docs/huggingface_hub/package_reference/hf_api#huggingface_hub.HfApi.paper_info)、[HF字段实现](https://github.com/huggingface/huggingface_hub/blob/main/src/huggingface_hub/hf_api.py)、[HN搜索API](https://hn.algolia.com/api)。

本次不新增4套未授权采集器，不借用浏览器私有登录材料，也没有启用付费数据服务。后续每接一类来源，只补一个明确的采集适配层并复用现有研究链路。

## 精简了什么，保留什么

- **移除新轮次的跨轮候选积压逻辑**：每轮重新扫固定窗口，已选去重；同轮失败仍保留断点。
- **消除未来资料的研究正文重复**：新策略的sources只存来源卡，完整单篇分析只在reports；不回写旧来源卡。
- **只维护一个正式阅读索引**：首页保持入口，索引由已接受产物派生；旧手工索引保留为区外历史快照，不再同时手工更新两份最新导读。
- **README与工作流目录去掉验收流水账**：历史文档与回执仍在原处，用户先看到当前怎么用。
- **MVP只描述当前流程**：移除尚未使用的机器人PR合并、跨轮游标与积压方案，避免和已落地的受限普通推送并存；早期方案仍可从Git历史查询。
- **运行回执不再充当阅读目录**：索引不列test与证明文件的正文；仍保留指向准入记录的证据入口。

独立审阅、一次有限修订、人工写作确认、未知请求不重发、预算预留、创建式准入和人工笔记保护直接支撑可靠性，本次不删除。历史散列侧文件、旧配置和prompt版本已经绑定已有结果，不能为了目录整齐删改；本次也不重构整套回执格式。

## 当前证据能支持多深的趋势

真实仓库按新策略只读试选30份历史文件，涉及13个原始来源，实际研究/采集日期覆盖2026-10-18至10-30，约12天。配置180天不等于已经拥有180天连续研究。经典论文可作背景，但不能把“今天读了旧论文”伪装成几个月持续跟踪。

要形成可信长期判断，仍需积累跨月资料、比较相同问题的可比证据、记录反例及更新历史；不能靠增加报告篇数或仅更换模型把当前样本写成行业趋势。
