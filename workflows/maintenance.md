# 资料去重与更新规范

## 新增前先查全库

搜索范围是整个 `sources/`，而非当前主题或当前文件夹。资料可以属于多个主题，只增加 `topics`，不复制文件。按下列顺序检查，但只要任一身份键命中已有记录，就先检查该记录；不要只在上一步没有键时才比较下一项。

1. **arXiv 基础编号**：去掉链接、`.pdf` 和 `vN` 版本后缀，旧式分类统一小写。`abs`、`pdf` 和不同版本属于同一篇论文。
2. **DOI**：去掉 `doi:` 或 DOI 链接前缀、首尾空白，统一小写。arXiv 预印本与后来的期刊版本若是同一研究，补充 DOI 并沿用原记录。
3. **原始来源 URL**：使用原文或 canonical 地址，避免转载和跳转地址。规范化协议与主机名大小写、默认端口、空路径 `/`，去掉 `#fragment` 及明确的跟踪参数（`utm_*`、`fbclid`、`gclid`、`dclid`、`msclkid`、`mc_cid`、`mc_eid`）。保留可能影响内容的其他查询参数、查询顺序、路径大小写、末尾斜杠与 `www`；不盲目合并 HTTP/HTTPS。
4. **标题与作者复核**：同一文章可能更换网址、标题或发布平台，机器键无法覆盖全部情况。相似标题是人工核查线索，不能直接当作重复。

可复现的检索示例（替换为真实编号、DOI 或域名）：

```sh
rg -n -i -- 'arxiv_id:|doi:|source_url:' sources
rg -n -F -- '2501.12345' sources
rg -n -i -F -- 'example.com/post' sources
```

校验器检查显式填写的 arXiv ID、DOI 和规范化 URL 是否跨记录重复。它不会联网查重，也不会推断重定向或 arXiv 与 DOI 的对应关系，因此录入前仍需人工核对。博客解读论文是两份不同的来源，分别建 `blog` 和 `paper`，通过 `related_sources` 关联。

## 新建、更新和冲突

- **新来源**：复制模板，生成一个 UUID v4，按类型加 `paper-` 或 `blog-` 前缀。填写字段后才保存为正式来源记录；不要使用模板中的空值提交。
- **已有来源或新版原文**：修改已有文件，沿用 `id` 和 `collected_at`。核实后补充来源信息、`source_version`、变更内容，修改 `updated_at`，在正文“更新记录”注明日期、原版本、新版本及影响。`published_at` 保持首次发布日期；日期不明时保留 `null`。
- **元数据冲突**：暂停合并，打开原文核实身份。记录冲突与证据，不用“最后写入获胜”的方式覆盖已有信息。
- **确认为重复的已有记录**：人工选定保留的 ID，逐段合并双方笔记，更新全库关联 ID 和路径，再处理重复文件。不能在未确认笔记与关联已保全时删除。初始化不会执行这种合并。
- **未知字段或新格式**：先更新 Schema 与校验器，再迁移；不要默默改写旧字段含义。

## 人工内容保护

正文全部视为人工内容，包括摘要、批注、证据和结论。`status`、`topics`、`related_sources`、`related_notes` 也由人工维护。来源变化不应重置阅读状态、删去研究关联或清空旧笔记。

当前所有更新均为人工操作。每次更新先查看已有内容和 Git 差异，按字段、按段落修改；保留历史判断，并写明新证据为何改变判断。不要用模板覆盖已有文件，也不要因来源版本更新而重新生成整篇 Markdown。Git 历史提供追踪能力，但不能替代笔记保护。

上述约定继续适用于正式研究资料。离线骨架仅在 `test/<topic>/` 中创建明确标记的虚构产物；已有文件包含测试产物也不覆盖。测试期间查重仍读取全库身份，正式来源的新版只产生独立测试更新建议，不写回原文件。以后新正式材料按主要研究方向分目录，既有文件本轮不搬迁，多主题不复制来源。见[离线运行说明](offline-research.md)。

`config/legacy_sources.yaml` 只豁免初始化前的 `sources/papers/test.md`。迁移时先人工补齐 Frontmatter，再移除该项；不改写既有正文。清单的 `files` 可以变成 `[]`，但不能用于豁免新增资料。

## 提交前

在仓库根目录运行 `python3 workflows/validate.py`（需 PyYAML）及 `git diff --check`，再检查暂存差异。确认没有重复来源、未解析的关联、冲突标记或密钥。只提交研究材料和明确需要的配置；Obsidian 本地配置继续留在本机。
