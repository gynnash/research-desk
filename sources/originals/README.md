# 原文归档

本目录按研究方向保存正式准入的原文抽取快照：`<方向>/<source-id>-<snapshot-sha256>.md`。来源卡保留唯一身份，归档保存当时取得的正文；二者分别链接，不创建重复来源身份。

论文优先官方HTML，其次提取同版本PDF；博客保存明确文章容器中的正文。归档包含来源、作者、日期、获取记录、章节与内容散列。它是便于GitHub和Obsidian阅读的抽取文本，不是网页截图或PDF附件，不保证图表、公式与原始版式完整。全文不可得时如实保存摘要并标明降级。

研究模型仍按预算读取正文或节选，归档范围与模型实际阅读范围分开记录。不能因为这里保存了完整抽取文本，就把旧摘要报告改称全文研究。

正式原文由确定性准入新增；已有文件和人工笔记不覆盖。精确重放检查点在`reports/test/<方向>/research-batches/<批次>/items/<来源>/original.yaml`，用于断网审阅与补跑；日常阅读使用本目录的Markdown。
