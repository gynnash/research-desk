# 原始论文与博客

按研究方向保存原文抽取快照：`<方向>/<source-id>-<snapshot-sha256>.md`。来源身份仍由 `sources/papers/` 和 `sources/blogs/` 记录，不复制来源身份。

`status: collected`、`research_performed: false` 表示仅采集保存，还没有进行全文研究或独立审阅；其他快照随正式研究准入新增。归档正文量与模型实际阅读范围分别记录，不能把旧摘要报告改称全文研究。

论文优先官方 HTML，其次同版本 PDF；博客提取文章正文。不保存可执行网页、图片和原版式，不保证图表及公式完整。真实研究的精确阅读检查点仍保留，用于审阅和补跑。
