# 原始研究资料

- `papers/`：论文来源及阅读笔记。
- `blogs/`：技术博客来源及阅读笔记。

每篇原文只建一条记录；同一论文的多个版本更新同一记录，博客对论文的解读是独立资料，可用 `related_sources` 关联。研究方向用 `topics` 标记，不复制资料到多个主题目录。

新增资料先[去重](../workflows/maintenance.md)，再复制[模板](../workflows/templates/)，填写 [Frontmatter](../workflows/source-schema.md)。文件名建议 `<id>.md`。优先保存来源链接、必要摘录与自己的笔记；不要提交整篇付费原文、登录凭据或未经允许的材料。

`papers/test.md` 为初始化前已有文件，暂保留为显式旧资料例外。
