# Agent记忆的价值在哪里：从提前压缩到完整证据交付


研究问题不是Agent是否需要记忆，而是：提前组织历史，何时能比保留原始记录、按题读取更有效？《MemoryTax》在一段可装入上下文的对话上发现，预建事实或图谱可能付出写入损失与建库成本；《MOSAIC》却显示，在固定阅读器和预算下，文本记忆组织也能超过原生多模态平坦检索。两者的张力可由证据路径解释：结构化既可能删除未来问题需要的细节，也可能帮助完整推理链进入实际请求。当前较稳妥的回答是，应比较表示保真、链条交付、读取能力与全周期成本的组合，而非给“原文搜索”或“结构化记忆”判定普遍胜负。这是两个同期独立来源支持的研究线索，不是已经验证的通用架构结论。

这是初始批次，尚无历史积累。以下是本批资料的比较与研究线索，不能据此判断跨时间的行业趋势。

## 方法为何不同，结论怎样比较

一、先区分“保存历史”和“提前决定历史的含义”。《MemoryTax》的设计选择是比较信息筛选发生在提问前还是提问后：Mem0逐轮抽取事实，附加日期，回答时最多取200条且不重排；Zep按会话建立时序图，取前20条边；BM25保留原始轮次，取前8轮及各自前后2轮；编码代理则逐题进入全新容器，自行读取对话文件。这不是跨题学习实验。《MOSAIC》把同一问题进一步拆成写入、检索、打包交付和阅读，指出索引中存在的证据不一定进入最终请求。两者共同揭示，记忆并非一个单独的存储盒子，而是一条持续筛选信息的通路；分歧在于前者主要检验提前抽取是否划算，后者检验各阶段在哪里丢失证据。对工程读者而言，先画清这条通路，才能判断换数据库、换写入器还是换访问流程真正对应当前故障。

二、强读取者不一定能补回上游损失，但损失也不全发生在写入。《MemoryTax》固定存储及检索结果、交换读取模型：弱模型写出的Zep图由三个模型读取，正确率分别为43%、43%、45%；最强模型写出的图则为66%、71%、87%。这支持“存储表示加检索结果”限制回答，却没有逐项分离抽取遗漏和检索遗漏。《MOSAIC》提供另一种定位：在784道可回答题、固定Gemini 3.5阅读器与Qwen3.7-Plus裁判下，金标准原生媒体的语义均分为0.783，通用描述与ASR为0.690；查询无关的结构化文本只回升至0.704，提升区间包含零。空间题中，显式关系描述比对象清单高15.4分，仍未追平原图。共同含义是，压缩应保留决定实体归属的关系，而不只是对象名称；但即使金标准符号事实齐全，得分也仅0.846，剩余误差还混合阅读、格式和裁判问题，不能全归咎于记忆。

三、结构化记忆的反例说明，“更接近原始信息”不等于“最终更有用”。《MemoryTax》在GPT-4o-mini下报告Mem0为78%，高于全文输入的74%；换成GPT-6 Luna后分别为80%和92%，Claude Opus 5.5下则同为95%。这显示收益依赖模型与配置，而非结构化必然无效。《MOSAIC》的固定阅读器轨道进一步报告，A-MEM的描述文本配置得分0.684，高于同表示平坦RAG的0.522，也高于原生多模态平坦RAG的0.641；完整链交付比例分别为0.787、0.698和0.466。该协议生产预算最多交付20个单元、每种模态三个媒体，总媒体不超过100 MB，原生证据可能在打包时被移除。因此，两篇材料不构成相互否定：提前组织可能损害保真，也可能改善预算内的证据组合。两项研究任务、模型和评分不同，不能把这些数字横向排榜，更不能把一个文本后端的局部优势推广到所有记忆架构。

四、成本优势必须和证据权限一起核算。《MemoryTax》报告Claude Opus 5.5驱动的Pi用6.95美元取得99%正确率，全文输入用17.84美元取得95%；但只有代理获得照片描述，七道增益题中六道属于照片证据组，其余88题只差一道。故不能把总体准确率差直接归因于搜索机制。另一方面，Mem0三个模型配置的建库费用均超过同模型全文输入完成152题的费用，作者估计需372、545、596题才能摊平建库投入，说明问题复用量会改变经济性。《MOSAIC》揭示另一种预算代价：冻结检索排序后，生产打包使语义均分从0.708降至0.670，完整链交付从0.675降至0.491。前者核算模型与嵌入调用费用，后者主要约束交付单元和媒体，不能据此比较谁更便宜；对部署者更有意义的是，同时记录建库、访问、缓存与证据被预算淘汰的代价，而不是只看单题输入长度。

五、回答正确不等于具备可靠的长期更新能力。《MemoryTax》的每道题启动新会话，主要考察对固定历史的访问，不能证明代理在持续交互中会巩固经验、维护冲突或遗忘信息。《MOSAIC》虽包含知识更新题，却是在既定历史中读取旧状态与新状态，而不是验证在线更新算法：一个案例只回答墙面变成鼠尾草绿，漏掉旧颜色到新颜色的变化，因而只得部分分。拒答同样不能单看一个指标，其端到端MiMo-V2.5原生ReAct可回答题得分0.732，正确拒答率仅0.410；MemoryOS正确拒答超过0.88，却对可回答题误拒超过0.61。两篇材料由此划出不同边界：固定历史上的高分不能替代持续记忆维护，保守拒答也不能替代证据利用。拒答题仍有问题形式线索，两项研究也未验证真实用户的授权、删除与保留期限，因此这些结果只能用于诊断当前证据访问，不能作为长期可靠性或隐私合规的证明。

## 记忆的优化对象可能不是条目，而是预算内可恢复的证据链

待验证的研究假设：在需要跨会话实体绑定、且未来问题尚不确定的任务中，记忆系统的有效性可能更取决于“预算内能否交付完整证据链，并在必要时恢复原始细节”，而不是记忆条目是否更精炼或索引是否原生。《MemoryTax》观察到固定弱写入结果后，升级读取者改善有限；《MOSAIC》则观察到文本组织可以超过原生平坦检索，因为后者的链成员可能被媒体预算移除。可能的解释是，两类失败其实发生在同一条可用性路径上：提前压缩使判别关系不可恢复，交付截断使仍被保存的关系暂时不可见，而读取错误又限制完整证据的兑现。由此推导，结构化表示更适合作为可回查的访问层，而不应未经检验就充当原始历史的唯一替代品；打包器也可能需要关注互相依赖的证据组合，而非只截取单条排名最高的内容。这不是两篇论文已经验证的混合架构，而是同时解释结构化损失与结构化收益的设计假设，其成立条件仍包括回查工具确实被使用、原始媒体可访问，以及额外访问费用可控。

一个足以改变判断的反例是：若未来问题集合稳定、所需属性有限，高质量写入器可能把必要信息一次性抽取完整，并在大量查询中充分摊销成本。此时原文回查只增加延迟和费用，“可恢复性”未必是最重要的优化目标。

完整链交付与得分共同改善，也可能部分来自检索底座、干扰项数量或阅读友好度，而非链完整性本身。《MOSAIC》的金标准事实条件仍有残余误差，《MemoryTax》的弱模型又可能不打开文件，因此保存更多信息并不保证它被正确利用。

该假设仅由两个同期独立来源的互补观察推导；没有共同基准上的混合架构对照，也没有自然积累的连续用户历史验证。

多跳必要事实标注可用于离线评测，但真实系统事先不知道金标准链，不能假定打包器能够无成本识别全部依赖；原始记录保留也需另行满足授权和删除要求。

还需要核实：

- 尚未执行：在统一文本与媒体权限的同一组单跳、多跳、状态变化任务上，比较仅抽取记忆、仅原始记录搜索、抽取记忆加原文回查三种条件；固定读取模型、提示与总调用费用，跨多个历史重复运行。
- 尚未执行：冻结检索候选，在相同单元、token和媒体预算下比较按单条排名截断与依赖关系感知打包；必要事实标注只用于离线评分，不向系统暴露。观察完整链交付是否提高，以及得分增益是否主要出现在原本缺一跳的题目。
- 尚未执行：记录写入后仍可恢复的必要事实、实际请求内容、工具调用、失败重试和端到端延迟，并人工审计回查前后的错误归因。若链交付改善但答案不改善，应转向检验读取或感知瓶颈，而不是继续扩大记忆。

## 如何理解当前结论

《MemoryTax》仅使用LoCoMo十段对话中的一段：419轮、152题，每个实验单元只有一次被接受的运行；失败或无答案尝试重跑且不计入报告成本。宽松模型裁判及至少一个错误答案键，使少数题目的差距尤其不稳。

《MemoryTax》的全部历史均可装入模型上下文，代理独享照片描述，记忆系统使用默认配置。其成本摊销点依赖当时标价、缓存与固定历史复用，不能直接用于超长历史或持续更新场景。

《MOSAIC》的人物、证据会话和媒体由合成流程构造，可回答题中99.5%涉及图像；视频挑战只有56至64道独立题，音频文本中残留副语言词汇线索。阶段差异仍混合上下文组成变化，不是完全隔离的因果效应。

《MOSAIC》全文存在局部表述不一致：结果表显示生产预算条件0.670、端到端条件0.653，正文却出现端到端相对前者“增加1.7分”的说法。本报告以表中数值为准，不沿用该方向性描述；部分阶段分差还涉及未展示精度，不能仅凭三位小数重算替代作者配对估计。

两项研究没有提供可直接对齐的共同任务、阅读模型、裁判、媒体输入与全周期预算。同期独立来源可以形成机制上的互补或反例，但不构成相互复现，也没有历史材料支持时间趋势。

## 值得继续追问的问题

- 结构化组织的收益究竟来自更高的完整链交付，还是更易阅读的表达？需要在同一任务上固定实际交付的必要事实、阅读器和预算，再只改变组织形式；这能区分“找得更全”与“表达得更好”。
- 保留原始记录并允许查询时回查，能否在同等总费用下弥补预抽取损失？缺少统一照片与媒体权限、计入失败重试、覆盖不同历史长度和查询复用量的比较；这些条件决定成本与保真之间是否存在真实交点。
- 完整证据齐全时，错误究竟来自感知、实体绑定还是裁判偏差？需要对原生媒体、人工核实事实和最终答案进行分层人工审计，并增加视频与词汇线索洁净的音频题，才能判断应改进表示还是读取能力。
- 固定历史问答的结论能否迁移到持续更新？缺少包含更正、撤回、过期和删除请求的连续交互证据，以及旧新状态同时被追踪的评测；这能区分一次性检索优化与真正的长期记忆维护。
