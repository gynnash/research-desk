# 智能体记忆：检索、证据组织与容量约束

《Edit-Your-Interest》摘要描述视频编辑中的有界特征缓存、相似性检索传播和多样性更新；《From Memory Hits to Answerable Evidence》摘要提出面向长期对话记忆的查询条件证据编译。《Context Engineering》、《Memory Blocks》的历史笔记分别记录上下文管理和记忆块的工程描述。它们可用于提出记忆选择与组织的研究问题，但《Edit-Your-Interest》并非通用智能体记忆研究，《From Memory Hits to Answerable Evidence》结果仅为作者报告，历史笔记也未经本次复核，不能据此确认效果或进行性能比较。

## 这些研究有哪些共同点与分歧

《Edit-Your-Interest》摘要描述在固定预算下缓存前序帧特征、按相似性检索并依据特征多样性更新；该设计属于视频编辑场景，不能直接证明其适用于智能体长期记忆。

《From Memory Hits to Answerable Evidence》摘要描述先定位支持材料、再在有限预算内选择互补证据并组织回答上下文；其报告的 LoCoMo 结果未在本次材料中独立核验。

《Context Engineering》历史笔记转述了文件卸载、摘要和按需加载等上下文管理机制；这些描述未经本次原文复核，不能据此确认其当前适用性或效果。

《Memory Blocks》历史笔记记录了以用途、容量等组织记忆块的工程视角；与《From Memory Hits to Answerable Evidence》的查询条件证据编译并置，可形成“持久组织”与“任务时组装”的研究问题，但不能据此认定两者互补或孰优孰劣。

《Edit-Your-Interest》讨论视频帧特征传播，《From Memory Hits to Answerable Evidence》讨论长期对话中的回答证据编译；任务与对象不同，现有材料不支持跨领域性能排名。

## 值得深入研究的线索

以下是基于当前材料提出的研究线索与待验证判断，不能据此确认行业趋势。

### 检索命中之后，证据如何变成可回答上下文？

待验证研究假设：对长期记忆检索结果增加面向查询的证据选择与组织步骤，可能比直接呈现检索单元更能控制冗余并保留回答所需支持。《From Memory Hits to Answerable Evidence》摘要提出此类编译框架，《Context Engineering》历史笔记记录了卸载和摘要等上下文管理思路；现有材料不能证明该假设成立。

编译过程也可能遗漏必要证据，或增加延迟与成本。

《Context Engineering》是未经本次复核的历史笔记，不能作为机制有效的验证。

《From Memory Hits to Answerable Evidence》的实验结果与泛化表述仅为摘要中的作者报告。

《From Memory Hits to Answerable Evidence》仅有摘要，缺少足以独立核查的实验设置、成本口径和统计不确定性。

《Context Engineering》仅为历史笔记；两份材料来自不同原始来源，不构成相互验证。

还需要怎样验证：

- 在同一长期对话任务与模型上，比较直接呈现检索结果和查询条件证据编译，并预先固定上下文预算。
- 由盲评者评估答案正确性、支持证据完整性和无关信息比例，同时记录延迟与token成本。
- 在多个数据集及独立随机种子下重复实验，公开评估口径和失败案例。

### 容量受限时，记忆选择与更新规则值得独立评测

待验证研究假设：容量受限的记忆若结合查询相关性与冗余控制，可能在预算内保留更多有用信息。《Edit-Your-Interest》描述视频特征多样性更新，《Memory Blocks》历史笔记描述有容量约束的记忆块；这些材料不能证明策略可迁移至智能体记忆或能提升实际效果。

视频特征的多样性不等同于对话事实的价值、时效性或可信度。

固定容量和去冗余可能丢弃低频但关键的信息；容量限制本身也不保证记忆质量。

《Memory Blocks》是未经本次复核的历史项目方博客笔记，不构成性能证据。

《Edit-Your-Interest》是视频编辑摘要，不是智能体记忆实验；《Memory Blocks》是历史笔记。

当前材料没有针对记忆写入、遗忘、冲突更新及长期正确性的共同评测。

还需要怎样验证：

- 在长期对话任务中比较不同容量、相关性选择与冗余控制策略，并保持检索和回答组件一致。
- 分别测量重要信息保留、过时或冲突记忆处理、最终回答正确性及存储成本。
- 使用跨会话、跨任务测试及人工核验的事实来源标签，检查稳定性并识别误删风险。

## 当前结论的边界

《Edit-Your-Interest》、《From Memory Hits to Answerable Evidence》均仅有摘要，缺少可供本次复核的全文、完整实验设置和独立复现；《From Memory Hits to Answerable Evidence》摘要未提供成本指标定义及统计不确定性。

《Edit-Your-Interest》研究视频编辑特征缓存，不直接研究通用智能体的工作记忆或长期记忆。

《Context Engineering》、《Memory Blocks》为历史笔记，未经本次独立原文复核；其中转述的主张不能升格为本次核验事实。

材料没有统一任务或评测条件，不支持因果结论、行业趋势或方法排名。

## 接下来值得追问什么

- 查询条件证据编译在不同长期对话任务及独立复现中是否仍有收益？
- 记忆预算受限时，如何评估证据的互补性、冗余程度和回答所需的完整性？
- 持久记忆块、文件卸载或摘要与查询时证据编译如何组合，是否会导致信息丢失或冲突？

阅读说明：《Edit-Your-Interest》、《From Memory Hits to Answerable Evidence》仅覆盖论文摘要；《Context Engineering》、《Memory Blocks》为未经本次独立原文复核的历史人工笔记。历史笔记中的转述不能视为本次核验事实；来源有关联不构成独立验证，现有材料不足以推断行业趋势、因果关系或跨方法性能排名。
